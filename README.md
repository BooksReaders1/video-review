# 局域网文件浏览器

一个基于 Flask 的轻量级局域网文件浏览系统，支持视频、图片、文本文件的在线预览和播放。

## 功能特性

### 📁 文件浏览
- 支持文件和文件夹的列表/网格视图切换
- 按名称、类型、日期排序
- 面包屑导航，快速返回上级目录
- 支持长路径（Windows UNC 路径）

### 🎬 视频播放
- 在线流式播放视频文件
- 支持多种视频格式：mp4, mkv, avi, mov, flv, wmv, rmvb
- **视频播放位置记忆**：返回后再次播放可定位到上次浏览位置
- 全屏播放支持

### 🖼️ 图片预览
- 点击图片即可预览大图
- 支持格式：jpg, jpeg, png, gif, bmp
- 模态框展示，支持关闭操作

### 📄 文本文件预览
- 支持多种文本格式预览：txt, log, md, json, xml, yml, py, js, html, css 等
- 自动检测文件编码（支持 UTF-8, GBK 等）
- 最大支持 10MB 文本文件预览

### 🔍 搜索功能
- 支持文件名和文件夹名搜索
- 实时显示搜索结果
- 搜索结果支持点击跳转到对应位置

### 🎨 缩略图
- 视频和图片自动生成缩略图
- **异步生成**：不阻塞文件列表加载，缩略图完成后自动回显
- 缩略图缓存，避免重复生成

## 技术栈

- **后端**: Python + Flask
- **前端**: 原生 HTML/CSS/JavaScript
- **视频处理**: ffmpeg-python
- **图片处理**: Pillow (PIL)
- **编码检测**: chardet

## 安装与运行

### 环境要求
- Python 3.7+
- ffmpeg (系统级别安装)

### 安装依赖
```bash
pip install flask ffmpeg-python pillow chardet
```

### 配置
修改 `main.py` 中的 `BASE_DIR` 为你的视频/文件目录路径：
```python
BASE_DIR = "D:/BaiduNetdiskDownload/shixi/Tools/beifen"  # 替换为你的实际路径
```

### 启动服务
```bash
python main.py
```

服务将在 `http://0.0.0.0:5000` 启动，局域网内其他设备可通过 `http://你的IP:5000` 访问。

## API 接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/files/<path>` | GET | 获取指定路径下的文件列表 |
| `/files/<path>?sort=name&type` | GET | 获取排序后的文件列表 |
| `/search?q=keyword` | GET | 搜索文件 |
| `/stream/<path>` | GET | 流式传输文件（视频/文本） |
| `/thumbnail/<filename>` | GET | 获取缩略图 |
| `/player?path=<path>&back=<back_url>` | GET | 视频播放器页面 |

## 使用说明

1. **浏览文件**: 点击文件夹进入，点击文件进行预览或播放
2. **切换视图**: 点击右上角"列表视图"/"平铺视图"按钮切换显示方式
3. **排序**: 点击"名称"/"类型"/"日期"按钮进行排序
4. **搜索**: 在顶部搜索框输入关键词，点击搜索或按回车
5. **返回**: 点击左上角"返回上级"或面包屑导航返回
6. **视频播放**: 点击视频文件开始播放，支持进度条拖动
7. **图片预览**: 点击图片全屏查看
8. **文本预览**: 点击文本文件在模态框中预览内容

## 注意事项

- 首次访问含大量视频的目录时，缩略图生成可能需要一些时间（异步进行，不影响浏览）
- 文本文件预览最大支持 10MB，超过将拒绝预览
- 视频播放依赖于浏览器的 HTML5 支持
- 建议使用 Chrome、Edge 等现代浏览器
